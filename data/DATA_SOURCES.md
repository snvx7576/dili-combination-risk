# Data Sources and Provenance

Project: Multi-Drug Combination Hepatotoxicity Risk Prediction, by Shivam Kumar.

This folder holds the processed fixed-database files that the demo and the models read. Every file was built between 20 and 21 November 2026 from public sources only. Models read these files; they never edit them. Any change creates a new version file, so the numbers in the project paper stay exactly reproducible.

Summary of the independent verification of the pharmacokinetic and metabolite data (full report in `verification_report_returned_data.md` in this folder): all 1,336 DILIrank drug names were present in both returned research files, with exact matches and none missing. Values were spot-checked against the project's hand-verified reference values and against standard labels. Two errors in the returned data were found and corrected by override in the app data, with the raw returned files kept unchanged for audit: the rabeprazole maximum doses, and an aspirin row that described the wrong formulation. Where a label gave only a range, a typical value was derived mechanically as the midpoint of that range and flagged per cell, never invented.

## 01_DILIrank_2.0_Labels.csv

- What it is: the frozen label table for all 1,336 drugs in DILIrank 2.0: LTKB identifier, compound name, SeverityClass, label section, and vDILI-Concern category (217 vMost, 351 vLess, 414 vNo, 354 Ambiguous).
- Source: DILIrank 2.0, FDA Liver Toxicity Knowledge Base (LTKB), U.S. Food and Drug Administration. https://www.fda.gov/science-research/liver-toxicity-knowledge-base-ltkb/drug-induced-liver-injury-rank-dilirank-20-dataset
- Citations: Chen M, et al. (2016); Olubamiwa et al. (2025).
- Built: 20 November 2026.
- How it was processed: downloaded once from the official FDA page and frozen as the project's single source of truth for liver-injury concern. Category counts were verified against the published dataset totals before freezing. This file is the reference every other file is mapped to, and it is not regenerated by any model run.

## 08_Structure_Alert_Matches_v1.csv

- What it is: one row per matched drug (1,224 drugs): PubChem CID, DILIrank concern and severity, total alert count, total alert points, the matched alert names, and one 0/1 column for each of the 13 alerts.
- Source: structures from PubChem (Kim S, et al. 2023, https://pubchem.ncbi.nlm.nih.gov), with 6 exact-match recoveries from ChEMBL (Zdrazil B, et al. 2024, https://www.ebi.ac.uk/chembl/), giving final structure coverage of 1,230 of 1,336 drugs (92.1%). The 13-alert library is the project's own structural alert library v1: quinones, epoxides, anilines, hydrazines, nitroaromatics, thiophenes, furans, thioureas, carboxylic acids (acyl glucuronide precursors), Michael acceptors, haloacetamides, aldehydes, and phenols (quinone-imine precursors).
- Built: 20 November 2026.
- How it was processed: each drug's SMILES string was matched against the 13 alert patterns using RDKit substructure matching with SMARTS patterns. The result is deterministic: the same structure and the same library always give the same row. Headline check: 560 of 1,224 drugs carry at least one alert, and the alert rate is nearly identical for vMost (48.8%) and vNo (45.6%) drugs, which is why alerts in this project add a note and points only, never a verdict.

## 10_PK_Table_v1_Returned_Verified.csv

- What it is: the pharmacokinetic table used by the temporal model: 1,483 rows covering all 1,336 drugs, one row per formulation, with Tmax (typical, minimum, maximum), half-life (typical, minimum, maximum), usual single dose, maximum single dose, maximum daily dose, bioavailability, protein binding, main clearing enzymes, active-metabolite flag, and a source name and source URL for every row.
- Source: delegated label research compiled from primary public sources, in this order of weight: FDA labels via DailyMed (1,190 rows), FDA accessdata label PDFs (67 rows), UK summaries of product characteristics via medicines.org.uk (44 rows), and PubMed/PMC articles (61 rows), with small numbers from other public sources. Source columns are preserved in the file so any value can be traced.
- Built: returned and verified 21 November 2026.
- How it was processed: the returned table was checked before it entered the fixed database. Coverage was confirmed complete: all 1,336 DILIrank names present, exact match. Spot checks against the project's hand-verified reference values passed (diclofenac sodium delayed-release Tmax 2 h; diclofenac extended-release Tmax 5.3 h against a verified 5.25 h; amoxicillin Tmax 1.5 h and half-life 1.36 h; atorvastatin half-life 14 h). Where a label gave only a range and left the typical cell blank (537 cells), the typical value was derived mechanically as the midpoint of the label range and flagged in the per-cell derived column; no value was guessed. Two returned errors were corrected in the app data by project override, with this raw file kept unchanged for audit: the rabeprazole maximum doses (returned as single 100 mg and daily 120 mg; corrected to the standard labelled maximum of 20 mg and 20 mg) and the aspirin row, which described the parent compound in a 75 mg antiplatelet formulation, while the project model uses the verified salicylate values. Extreme values that look like errors are genuine label values (for example the amiodarone half-life of 1,392 h); depot and non-oral rows are excluded from the app by its oral-formulation filter. Project-verified reference values take precedence over returned values for the six original demo drugs, so every published scenario number remains exactly reproducible. Status, stated honestly: returned values beyond the spot checks are label-sourced but not yet individually re-verified, and the app footer states this provenance.

## 11_Metabolites_v1_Returned.csv

- What it is: the metabolite list: 1,469 rows covering all 1,336 parent drugs, with metabolite name, type (ACTIVE, TOXIC, BOTH, or none known), whether the metabolite is more toxic than the parent, the forming enzyme, the injury mechanism where known, and source name and source URL per row.
- Source: delegated research from public sources: DailyMed labels (554 rows), NCBI resources (499 rows), PMC/PubMed (282 rows), and FDA sources (57 rows). Source columns are preserved in the file. LiverTox (NCBI Bookshelf, National Library of Medicine) was used as a clinical cross-reference during the research.
- Built: returned and verified 21 November 2026.
- How it was processed: coverage was confirmed complete against the DILIrank name list before loading. The paracetamol row was verified exactly: NAPQI, type TOXIC, more toxic than parent YES, formed mainly by CYP2E1. In total, 142 parent drugs have at least one TOXIC or BOTH metabolite, and 815 rows record that no active or toxic metabolite is known. In the app these flags are shown as information; in Model v2.1 the temporal hazard is adjusted by a factor of 1.25 where a metabolite is more toxic than its parent, or 1.10 where a toxic metabolite is present but not more toxic, capped at a hazard of 1.0.

## verification_report_returned_data.md

- What it is: the project's own verification report for files 10 and 11, written when the returned research was checked and loaded on 21 November 2026.
- Contents: coverage counts, the spot checks performed and their outcomes, the five issues found (blank typical values, the rabeprazole dose error, the aspirin formulation error, genuine extreme label values, and the diclofenac maximum-daily-dose difference between labels), the precedence rule applied, and the honest status note on re-verification.
